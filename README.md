# Дом — движок

Открытая часть личного проекта «Дом»: интерактивной 3D-модели жилого дома, участка и коммуникаций на three.js. Модель работает как одна HTML-страница и открывается в браузере и на iPhone с экрана «Домой».

В репозитории лежат приёмы, на которых держится производительность и детализация модели, и демо-сцена, где их видно в работе. Сам дом, его планировка, камеры, коммуникации, адреса и доступы сюда не входят: эти данные личные.

## Что внутри

| Файл | Что делает |
|---|---|
| `js/merge.js` | **Склейка неподвижных деталей.** Тысячи мелких деталей (окна, отливы, водостоки) склеиваются в общие сетки по материалу и квадратам плана 8 × 8 м. Камера по-прежнему пропускает то, что вне кадра, а клик по детали показывает ту же карточку. Совпадающие материалы сначала сводятся к одному. В модели дома число вызовов отрисовки упало с ≈2 600 до ≈1 200 за кадр без единого изменения в картинке. |
| `js/micro.js` | **Фактура без текстур.** Это один общий шейдер на все материалы. Он даёт мелкий рельеф 2–3 см, пятна выгорания цвета и неравномерный блеск. Рельеф гаснет с расстоянием, чтобы дальние поверхности не рябили, а стекло и полированные поверхности остаются чистыми. Не требует ни файлов, ни памяти, ни новых шейдерных программ. |
| `js/house.js` | **Процедурный кирпичный дом.** В нём есть цоколь, межэтажный пояс, карниз, окна с импостом, подоконниками и перемычками, вход с дверью, ступенями и козырьком, вальмовая кровля с коньком, софитами и водостоками, а также дымовая труба. |
| `js/sun.js` | **Солнце и луна по дате и месту**: азимут и высота, фаза луны. |
| `js/demo.js` | Демо: улица из пяти домов под солнцем выбранного часа. На панели видно, сколько деталей склеено и сколько вызовов отрисовки стоит кадр. |

## Как запустить

Нужен любой локальный веб-сервер в папке репозитория:

```
python -m http.server 8000
```

Затем откройте http://localhost:8000. Библиотека three.js r128 загружается с jsDelivr.

## Как подключить к своей сцене

Подключите `js/micro.js` и `js/merge.js` после three.js, затем:

```js
const m = MICRO.apply(new THREE.MeshStandardMaterial({color: 0xb0a090}));   // фактура
// … построить сцену …
const r = autoMerge(group, {cell: 8, keep: o => o.userData.moving});        // склейка, когда всё стоит на местах
console.log(r);   // {meshes, joined, made, materials}
```

`autoMerge` вызывается один раз, после построения сцены. Подвижные детали (двери на петлях, ворота) надо исключить через `keep`. Материалы, которые позже меняются (например, прозрачность земли), передаются в `fixed`.

## Ограничения

- three.js r128 (глобальный `THREE`). На более новых версиях могут понадобиться правки имён чанков шейдера.
- Рельеф в `micro.js` работает только в WebGL 2. В WebGL 1 остаются цветовые пятна.
